# Sanity Test Plan

## Project

School Management System

---

# Objective

The objective of Sanity Testing is to verify that recently implemented features, bug fixes, or minor code changes are working correctly without affecting the related functionality.

Sanity Testing is performed before executing full Regression Testing.

---

# Scope

This Sanity Test covers:

- Bug Fix Verification
- Modified Features
- Related Functionalities
- Critical Business Workflow

---

# Entry Criteria

- Bug Fix Deployed
- QA Environment Ready
- Smoke Test Passed
- Build Available

---

# Exit Criteria

- All Sanity Test Cases Passed
- No Blocker Issue Found
- Build Ready For Regression Testing
