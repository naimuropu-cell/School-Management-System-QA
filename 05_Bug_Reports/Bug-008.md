# BUG-008 - Generated Seat Plan Does Not Contain Seat Allocation Details

## Bug ID

BUG-008

---

## Module

Examination

---

## Feature

Seat Plan

---

## Bug Title

Generated Seat Plan does not contain seat allocation details.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Examination |
| Feature | Seat Plan |
| Browser | Google Chrome |

| Build | Current Testing Build |

---

## Preconditions

- User is logged in as **Admin** or **Examination Controller**.
- An examination has been created.
- Students are assigned to the selected class and section.
- Seat Plan module is accessible.

---

## Steps to Reproduce

1. Login as **Admin**.
2. Navigate to **Examination → Seat Plan**.
3. Select the following:
   - **Exam:** Mid Term
   - **Class:** 10
   - **Section:** AA
4. Select the students.
5. Click **Generate Seat Plan**.
6. Observe the generated seat plan.

| Field | Value |

## Expected Result

The generated Seat Plan should include complete seating information for each student, such as:

- Student Name
- Roll Number
- Admission Number
- Class
- Section
- **Seat Number**
- **Room Number**
- **Hall Name**
- **Bench Number**
- **Row/Column or Seating Position**
- Exam Name

The output should be ready for examination hall usage.

---

## Actual Result

The generated Seat Plan only displays basic student information such as:

- Student Name
- Class
- Roll Number
- Admission Number
- Student Photo

No seat allocation details are generated, including:

- Seat Number
- Room Number
- Hall Name
- Bench Number
- Seating Position

As a result, the generated report cannot be used as an actual examination seat plan.

---

## Impact

- Students cannot identify their assigned examination seats.
- Invigilators cannot arrange students according to seating assignments.
- Examination seating management becomes impossible.
- Generated Seat Plan is incomplete and unusable for examination purposes.

## Root Cause (Possible)

- Seat allocation logic is not executed during seat plan generation.
- Seat assignment data is not retrieved from the database.
- Seat allocation fields are missing from the report template.
- Report generation only binds student profile information instead of examination seating data.

---

## QA Comments

Although the system successfully generates a Seat Plan report, it fails to include the primary purpose of the feature—seat allocation information. Without seat numbers and room assignments, the generated output cannot be used during examinations and does not fulfill the intended business requirement.

---

## Suggested Fix

- Implement automatic or manual seat allocation before report generation.
- Include Seat Number, Room Number, Hall Name, Bench Number, and Seating Position in the generated report.
- Ensure the report retrieves seat allocation data from the database.
- Validate the generated Seat Plan against actual seating assignments before release.
