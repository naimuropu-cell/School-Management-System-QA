# BUG-015 - Guardian Information Form Does Not Load After Completing Personal Information

## Bug ID

BUG-015

---

## Module

Student Admission

---

## Feature

Admission Form

---

## Bug Title

Guardian Information form does not load after completing Personal Information, preventing completion of the student admission process.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Student Admission |
| Feature | Admission Form |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Admin |
| Build | Current Testing Build |

---

## Preconditions

- User is logged in as **Admin**.
- User has permission to create new student admissions.
- Admission module is accessible.

---

## Steps to Reproduce

1. Login as **Admin**.
2. Navigate to **Student Admission → Admission Form**.
3. Fill in all mandatory fields under **Personal Information**.
4. Click **Next** to proceed to the **Guardian Information** section.
5. Observe the system behavior.

---

## Test Data

| Field | Value |
|--------|-------|
| Student Name | Test Student |
| Class | Class 10 |
| Section | A |
| Gender | Male |

---

## Expected Result

After completing the Personal Information section, the system should:

- Load the Guardian Information form.
- Display all guardian-related input fields.
- Allow users to continue the admission process.
- Save the complete student admission after all required information is provided.

---

## Actual Result

After clicking **Next**, the Guardian Information page does not load.

- No guardian fields are displayed.
- The admission workflow cannot continue.
- Student admission cannot be completed.

In some cases, the Personal Information appears to be partially saved, but the complete student profile is not created because the admission process cannot proceed.

---

## Impact

- Student admission process is blocked.
- Complete student records cannot be created.
- Guardian information cannot be captured.
- Admission workflow remains incomplete.
- Administrators cannot register new students successfully.

## Root Cause (Possible)

- Guardian Information page fails to render after navigation.
- Multi-step admission workflow is broken.
- Frontend routing or API response handling fails.
- Required Guardian Information component is not loaded.
- Backend validation or session state interrupts the workflow.

---

## QA Comments

This is a blocking issue because the admission process cannot progress beyond the Personal Information step. As a result, complete student profiles cannot be created, making the Student Admission module unusable for new admissions.

---

## Suggested Fix

- Verify the navigation between Personal Information and Guardian Information steps.
- Ensure the Guardian Information form loads correctly after completing Personal Information.
- Validate frontend and backend workflow for multi-step admission.
- Display an appropriate error message if the next step fails to load instead of stopping the process silently.
- Perform regression testing on the complete admission workflow after implementing the fix.
