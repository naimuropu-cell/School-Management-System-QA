# BUG-001 - Class Dropdown Remains Empty While Creating Homework

## Bug ID
BUG-001

---

## Module
Homework

---

## Feature
Add Homework

---

## Bug Title
Class dropdown remains empty while creating a new Homework.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Homework |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Admin |
| Build | Current Testing Build |

---

## Preconditions

- Admin user is logged into the application.
- At least one Class and Section already exist in the system.
- User has permission to create Homework.

---

## Steps to Reproduce

1. Login to the application as **Admin**.
2. Navigate to **Academics**.
3. Click **Homework**.
4. Click **Add Homework**.
5. Click the **Class** dropdown.

---

## Test Data

Existing Classes:
- Class One
- Class Two
- Class Three

---

## Expected Result

The system should display all active classes in the Class dropdown so that the user can select a class before creating Homework.

---

## Actual Result

The Class dropdown remains empty although multiple classes already exist in the system.

---

## Impact

- User cannot select a class.
- Homework creation cannot continue.
- Entire Homework module becomes unusable because Class is a mandatory field.

---

**Critical**

---

**High**

100%

## Root Cause (Possible)

- Class API is not returning records.
- Dropdown binding failed.
- Active classes are not loaded correctly.
- Permission or filtering issue.

---

## QA Comments

This is a blocking issue because Homework cannot be created without selecting a Class. The issue was reproduced multiple times after refreshing the page and logging in again.

---

## Suggested Fix

- Verify Class API response.
- Verify dropdown binding logic.
- Load all active classes.
- Display an informative message if no classes are available instead of leaving the dropdown empty.
