# BUG-012 - Grade Calculator Does Not Respond When No Grade System Is Configured

## Bug ID

BUG-012

---

## Module

Examination

---

## Feature

Grade Mapping / Grade Calculator

---

## Bug Title

Grade Calculator does not respond when no grade system is configured.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Examination |
| Feature | Grade Mapping |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Admin |
| Build | Current Testing Build |

---

## Preconditions

- User is logged in as **Admin**.
- No Grade System has been configured in the system.

---

## Steps to Reproduce

1. Login as **Admin**.
2. Navigate to **Examination → Grade Mapping**.
3. Verify that no Grade System exists.
4. Scroll to the **Grade Calculator** section.
5. Enter any valid mark (e.g., **80**).
6. Click **Calculate** (or perform the calculation action).
7. Observe the system behavior.

---

## Test Data

| Field | Value |
|--------|-------|
| Grade System | Not Configured |
| Marks | 80 |

---

## Expected Result

The system should prevent grade calculation and display a meaningful message, such as:

> **"No grade system has been configured. Please create a grade system before using the Grade Calculator."**

or

> **"Grade calculation is unavailable until a grade mapping is configured."**

The calculator should either be disabled or guide the user to configure a Grade System first.

---

## Actual Result

The Grade Calculator does not perform any calculation and provides no response, validation message, or error notification when no Grade System is configured.

---

## Impact

- Users cannot determine why the calculator is not working.
- Poor user experience due to lack of system feedback.
- Administrators may assume the calculator is broken.
- The workflow for configuring grade systems is unclear.

## Root Cause (Possible)

- Grade Calculator does not validate whether a Grade System exists before execution.
- Missing frontend validation for prerequisite configuration.
- Backend returns an empty response without handling the missing Grade System scenario.
- No user-friendly exception handling has been implemented.

---

## QA Comments

The Grade Calculator depends on an existing Grade System configuration. Instead of remaining unresponsive, the application should clearly inform users that grade mapping must be configured before calculations can be performed.

---

## Suggested Fix

- Check whether a Grade System exists before enabling the Grade Calculator.
- Disable the calculator until a valid Grade System is available.
- Display an informative validation message guiding the user to configure Grade Mapping first.
- Handle missing configuration scenarios gracefully on both the frontend and backend.
