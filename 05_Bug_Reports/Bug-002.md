# BUG-002 - Guardian Information Page Remains Blank During Student Admission

## Bug ID
BUG-002

---

## Module
Student Admission

---

## Feature
Guardian Information

---

## Bug Title
Guardian Information page remains blank after completing Personal Information.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Student Admission |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Admin |
| Build | Current Testing Build |

---

## Preconditions

- Admin user is logged into the application.
- Student Admission module is accessible.
- User has permission to create a new student admission.

---

## Steps to Reproduce

1. Login as **Admin**.
2. Navigate to **Student → Admission**.
3. Click **New Admission**.
4. Complete all required fields in the **Personal Information** section.
5. Click **Next** to navigate to the **Guardian Information** section.

---

## Test Data

Student Name: Test Student

Gender: Male

Date of Birth: 01/01/2015

Class: One

Section: A

---

## Expected Result

The Guardian Information page should display all guardian-related input fields such as:

- Father Name
- Mother Name
- Guardian Name
- Mobile Number
- Occupation
- Address
- Email
- Emergency Contact

allowing the admission process to continue.

---

## Actual Result

The Guardian Information page loads as a blank screen with no input fields displayed.

---

## Impact

- Student admission cannot be completed.
- Guardian information cannot be entered.
- Admission workflow is blocked.
- New student records cannot be created successfully.

---

## Root Cause (Possible)

- Guardian Information UI failed to load.
- Frontend rendering issue.
- Guardian form API returned empty response.
- JavaScript exception while loading the next step.
- Workflow navigation issue.

---

## QA Comments

This issue blocks the entire Student Admission process because guardian information is mandatory before saving a student record. The issue was reproduced multiple times after refreshing the page, logging in again, and testing with different student data.

---

## Suggested Fix

- Verify Guardian Information page rendering.
- Check API response for guardian form fields.
- Inspect browser console for JavaScript errors.
- Ensure workflow correctly navigates between admission steps.
- Display an error message if guardian data cannot be loaded instead of showing a blank page.
