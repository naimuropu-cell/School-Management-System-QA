# BUG-018 - Student Export Allows Exporting Without Applying Any Search Filter

## Bug ID

BUG-018

---

## Module

Student

---

## Feature

Student Export

---

## Bug Title

Student Export allows exporting reports without applying any search criteria, resulting in unnecessary or incorrect report generation.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Student |
| Feature | Student Export |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Admin |
| Build | Current Testing Build |

---

## Preconditions

- User is logged in as **Admin**.
- Student records exist in the system.
- Student Export module is accessible.

---

## Steps to Reproduce

1. Login as **Admin**.
2. Navigate to **Student → Student Export**.
3. Do not select any search filters (Class, Section, Academic Year, etc.).
4. Click **Export PDF** or **Export Excel**.
5. Observe the generated report.

---

## Test Data

No filters selected.

---

## Expected Result

The system should either:

- Require at least one search/filter before exporting.

OR

- Display a confirmation message:

> "Please select at least one filter before exporting."

---

## Actual Result

The system allows report generation without applying any filters, which may generate unnecessary or incorrect reports.

---

## Impact

- Users may accidentally export large datasets.
- Unnecessary server processing.
- Incorrect reports may be shared.
- Poor user experience.

---

## Severity

Medium

---

## Priority

Medium

---

## Bug Type

Validation / Business Logic

---

## Status

Open

---

## Reproducibility

100%

---

## Regression Required

Yes

---

## Root Cause (Possible)

- Search validation is missing before report generation.
- Export API accepts empty filter parameters.
- Frontend does not validate mandatory search criteria.

---

## QA Comments

Export operations should be controlled to prevent generating unintended reports and improve report accuracy.

---

## Suggested Fix

- Require mandatory search criteria before exporting.
- Display a validation message when no filter is selected.
- Optimize export functionality to prevent unnecessary report generation.
