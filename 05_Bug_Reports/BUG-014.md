# BUG-014 - Subject Group Can Be Created Without Selecting Required Subjects

## Bug ID

BUG-014

---

## Module

Class & Subjects

---

## Feature

Subject Group

---

## Bug Title

Subject Group can be created without selecting any subject or with only one subject.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Class & Subjects |
| Feature | Subject Group |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Admin |
| Build | Current Testing Build |

---

## Preconditions

- User is logged in as **Admin**.
- At least one subject exists in the system.
- Subject Group module is accessible.

---

## Steps to Reproduce

### Scenario 1 – No Subject Selected

1. Login as **Admin**.
2. Navigate to **Class & Subjects → Subject Group**.
3. Click **Add Subject Group**.
4. Enter a valid Subject Group Name.
5. Do **not** select any subject.
6. Click **Save**.

### Scenario 2 – Only One Subject Selected

1. Click **Add Subject Group**.
2. Enter a valid Subject Group Name.
3. Select only **one subject**.
4. Click **Save**.

---

## Test Data

| Field | Value |
|--------|-------|
| Subject Group | Science Group |
| Subjects Selected | None / One Subject |

---

## Expected Result

The system should validate the minimum required number of subjects before creating a Subject Group.

For example:

- At least **two subjects** must be selected.

If validation fails, an appropriate message should be displayed, such as:

> **"Please select at least two subjects to create a Subject Group."**

The Subject Group should not be created until the validation requirement is met.

---

## Actual Result

The system successfully creates the Subject Group even when:

- No subject is selected.
- Only one subject is selected.

No validation message is displayed.

---

## Impact

- Invalid Subject Groups can be created.
- Academic configuration becomes inconsistent.
- Subject Group functionality loses its intended purpose.
- Incorrect data may affect class, examination, and routine configurations.

## Root Cause (Possible)

- Minimum subject selection validation is missing.
- Business rules are not enforced before saving.
- Backend accepts incomplete Subject Group data.
- Client-side validation is not implemented.

---

## QA Comments

A Subject Group is intended to organize multiple related subjects. Allowing a Subject Group to be created without any subject or with only one subject violates the expected business logic and may lead to inconsistent academic configurations.

---

## Suggested Fix

- Enforce a minimum subject selection requirement before saving.
- Validate the selection on both the client-side and server-side.
- Display a meaningful validation message when the minimum requirement is not met.
- Prevent saving until the required number of subjects has been selected.
