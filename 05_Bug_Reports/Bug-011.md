# BUG-011 - Activity Feed Displays Incorrect Entity Type When a Teacher is Created

## Bug ID

BUG-011

---

## Module

Dashboard

---

## Feature

Activity Feed

---

## Bug Title

Activity Feed displays **"Staff Member"** instead of **"Teacher"** after creating a new teacher.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Dashboard |
| Feature | Activity Feed |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Super Admin |
| Build | Current Testing Build |

---

## Preconditions

- User is logged in as **Super Admin**.
- User has permission to create Teacher accounts.
- Dashboard Activity Feed is enabled.

---

## Steps to Reproduce

1. Login as **Super Admin**.
2. Navigate to **Staff Management → Teachers**.
3. Click **Add Teacher**.
4. Fill in all required teacher information.
5. Save the new teacher record.
6. Navigate to the **Dashboard**.
7. Observe the latest entry in the **Activity Feed**.

---

## Test Data

| Field | Value |
|--------|-------|
| Teacher Name | Test Teacher |

---

## Expected Result

The Activity Feed should accurately identify the created entity.

Example:

> **Super Admin created Teacher "Test Teacher".**

---

## Actual Result

The Activity Feed displays:

> **Super Admin created Staff Member "Test Teacher".**

instead of indicating that a **Teacher** was created.

---

## Impact

- Activity logs become inaccurate.
- User actions are misclassified.
- Audit history becomes misleading.
- Administrators may have difficulty identifying the exact entity created.
- Reduces the reliability of activity tracking.

## Root Cause (Possible)

- Activity Feed uses a generic **"Staff Member"** label for all staff-related entities.
- Entity type mapping is not differentiated between Teacher, Accountant, Librarian, HR, etc.
- Audit log records the parent entity instead of the specific role.

---

## QA Comments

Although this issue does not affect system functionality, it impacts the accuracy of audit logs and activity tracking. The Activity Feed should display the specific entity type (e.g., Teacher, Accountant, Librarian) instead of the generic label **Staff Member** to improve traceability and reporting.

---

## Suggested Fix

- Update the Activity Feed logging mechanism to record the specific entity type.
- Use role-based labels such as **Teacher**, **Accountant**, **Librarian**, or **HR** instead of the generic **Staff Member**.
- Verify activity logging across all staff creation workflows to ensure consistent and accurate audit records.
