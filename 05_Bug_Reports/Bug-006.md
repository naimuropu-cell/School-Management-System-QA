# BUG-006 - Exported PDF Displays Report Layout but Does Not Include Student List Data

## Bug ID

BUG-006

---

## Module

Student

---

## Feature

Student Export

---

## Bug Title

Exported PDF displays the report layout successfully but does not include the student list data.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Student |
| Feature | Student Export |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Admin |
| Build | Current Testing Build |

---

## Preconditions

- Admin user is logged into the application.
- Student records already exist in the system.
- User has permission to export student reports.

---

## Steps to Reproduce

1. Login as **Admin**.
2. Navigate to **Student → Student Export**.
3. Search or load the available student records.
4. Click **Export PDF**.
5. Open the generated PDF file.
6. Verify whether the student records are included in the exported report.

---

## Test Data

| Field | Value |
|--------|-------|
| Student Records | Existing records in the system |
| Export Format | PDF |

---

## Expected Result

The generated PDF should contain:

- School information
- Report header
- Student list
- Student details
- Total records (if applicable)

The exported PDF should accurately match the data displayed on the Student Export page.

---

## Actual Result

The PDF is generated successfully and displays the report layout/header; however, no student records are included in the report.

Only the report template is exported.

---

## Impact

- Exported reports become unusable.
- Users cannot print or share student information.
- Administrative reporting functionality fails.
- Report accuracy cannot be trusted.

## Root Cause (Possible)

- Student dataset is not passed to the PDF generation service.
- PDF template is rendered without binding the student data.
- Export query returns an empty dataset.
- Backend export API ignores applied filters or loaded records.

---

## QA Comments

Although the PDF generation process completes successfully, the exported document does not include the actual student records. This significantly reduces the usability of the export feature and may affect reporting and administrative operations.

---

## Suggested Fix

- Verify that the student dataset is correctly passed to the PDF generation engine.
- Ensure the PDF template binds all student records before rendering.
- Validate export API responses against the records displayed in the UI.
- Perform data consistency checks between the Student Export page and the generated PDF.
