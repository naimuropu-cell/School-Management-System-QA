# BUG-007 - Generated Fee Invoices Cannot Be Managed Due to Missing Invoice Actions

## Bug ID

BUG-007

---

## Module

Fees

---

## Feature

Fees Invoice

---

## Bug Title

Generated fee invoices cannot be managed because invoice action options are missing.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Fees |
| Feature | Fees Invoice |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Admin / Accountant |
| Build | Current Testing Build |

---

## Preconditions

- Admin or Accountant is logged into the application.
- At least one student exists.
- Fee structure has been configured.
- A fee invoice has already been generated successfully.

---

## Steps to Reproduce

1. Login as **Admin** or **Accountant**.
2. Navigate to **Fees → Fees Invoice**.
3. Generate a fee invoice for a student.
4. Return to the **Invoice List**.
5. Locate the generated invoice.
6. Observe the available action options for the invoice.

---

## Test Data

| Field | Value |
|--------|-------|
| Student | Existing Student |
| Invoice Status | Unpaid |
| Fee Structure | Configured |

---

## Expected Result

Each generated invoice should provide appropriate management actions, such as:

- View Invoice
- Collect Payment
- Update Payment Status
- Print Invoice
- Download Invoice
- Edit (if permitted)
- Cancel/Void (if applicable)

Users should be able to manage the invoice lifecycle directly from the invoice list.

---

## Actual Result

The generated invoice appears in the invoice list; however, no action options are available.

Administrators and Accountants cannot:

- View invoice details
- Collect payments
- Change invoice status
- Print the invoice
- Manage the generated invoice

The invoice remains in **Unpaid** status with no available management functionality.

---

## Impact

- Fee collection process is blocked.
- Invoice status cannot be updated.
- Payment workflow cannot be completed.
- Financial operations become incomplete.
- Generated invoices become unusable after creation.

---

## Severity

**Critical**

---

## Priority

**High**

Functional / Workflow

Open

## Reproducibility

100%

---

## Regression Required

Yes

---

## Root Cause (Possible)

- Invoice Action column is not rendered.
- Permission mapping for invoice actions is missing.
- Action buttons are hidden due to UI or frontend logic.
- Invoice management routes are not linked.
- Backend API for invoice actions is not integrated.

---

## QA Comments

Although invoice generation completes successfully, users cannot perform any subsequent invoice management activities. This breaks the complete fee collection workflow because invoices cannot be viewed, printed, or marked as paid.

---

## Suggested Fix

- Display all invoice management actions in the Invoice List.
- Verify role-based permissions for Admin and Accountant.
- Enable payment collection and status update functionality.
- Ensure View, Print, and Download actions are available.
- Validate the complete invoice lifecycle through regression testing after implementation.
