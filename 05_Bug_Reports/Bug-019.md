# BUG-019 - Duplicate Student Admission Number Is Accepted During Student Registration

## Bug ID

BUG-019

---

## Module

Student Admission

---

## Feature

Admission Form

---

## Bug Title

System allows duplicate Admission Numbers during student admission.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Student Admission |
| Feature | Admission Form |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Admin |
| Build | Current Testing Build |

---

## Preconditions

- Admin user is logged into the application.
- At least one student already exists with an Admission Number.
- Admission Number field is available during student admission.

---

## Steps to Reproduce

1. Login as **Admin**.
2. Navigate to **Student Admission → Admission Form**.
3. Create a student using Admission Number **ADM-1001**.
4. Save the student successfully.
5. Create another student.
6. Enter the same Admission Number **ADM-1001**.
7. Complete the remaining required fields.
8. Click **Save**.

---

## Test Data

| Field | Value |
|--------|-------|
| Admission Number | ADM-1001 |

---

## Expected Result

The system should validate Admission Number uniqueness and display an error message such as:

> **"Admission Number already exists."**

The duplicate student record should not be saved.

---

## Actual Result

The system accepts the duplicate Admission Number and successfully creates another student record with the same Admission Number.

---

## Impact

- Duplicate Admission Numbers cause student identification conflicts.
- Student records become inconsistent.
- Reports and searches may return incorrect results.
- Fee, Attendance, Examination, and Result modules may reference the wrong student.

---

## Severity

**Critical**

---

## Priority

**High**

---

## Bug Type

Validation / Data Integrity

---

## Status

Open

---

## Reproducibility

100%

---

## Regression Required

Yes

---
## Root Cause (Possible)

- Unique validation is missing for Admission Number.
- Database unique constraint is not implemented.
- Backend does not verify existing Admission Numbers before insertion.

---

## QA Comments

Admission Number is a unique identifier for every student. Allowing duplicate values may result in serious data integrity issues across multiple modules.

---

## Suggested Fix

- Implement both frontend and backend uniqueness validation.
- Add a database unique constraint for Admission Number.
- Display a validation message when a duplicate Admission Number is entered.
- Perform regression testing on student creation and import functionalities.
