# BUG-013 - No Option Available to Assign Fee Structures to Classes

## Bug ID

BUG-013

---

## Module

Finance

---

## Feature

Class-wise Fees

---

## Bug Title

No option is available to assign fee structures to classes.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Finance |
| Feature | Class-wise Fees |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Admin / Accountant |
| Build | Current Testing Build |

---

## Preconditions

- User is logged in as **Admin** or **Accountant**.
- Academic classes have already been created.
- Finance module is accessible.

---

## Steps to Reproduce

1. Login as **Admin**.
2. Navigate to **Finance → Class-wise Fees**.
3. Select any available class.
4. Observe the available actions on the page.

---

## Test Data

| Field | Value |
|--------|-------|
| Class | Any Existing Class |

---

## Expected Result

The system should provide an option to:

- Assign Fee Structure
- Create Fee Structure
- Edit Fee Structure
- Configure class-wise fees

so that fee structures can be assigned to the selected class.

---

## Actual Result

No option is available to assign or configure fee structures for any class.

The page only displays a message similar to:

> **"No fee structures configured for this class."**

There is no **Add**, **Assign**, or **Configure** button available.

---

## Impact

- Fee structures cannot be assigned to classes.
- Student invoices cannot be generated.
- Fee collection workflow cannot proceed.
- Entire Finance module becomes partially unusable.
- Downstream features such as Fee Invoice, Student Fees, and Payment Collection are blocked.

## Root Cause (Possible)

- Class-wise Fee assignment functionality is missing.
- Assign Fee action is not implemented or hidden.
- Permission configuration prevents displaying the action.
- UI component for fee assignment is not rendered.
- Backend endpoint for fee assignment is unavailable.

---

## QA Comments

The Class-wise Fees page allows users to view classes but provides no mechanism to configure or assign fee structures. Since fee assignment is the primary purpose of this feature, the current implementation blocks the entire fee management workflow.

---

## Suggested Fix

- Add an **Assign Fee Structure** button for each class.
- Allow administrators to create and assign fee structures directly from this page.
- Verify role-based permissions for Finance operations.
- Ensure assigned fee structures are immediately available for invoice generation and student fee management.
