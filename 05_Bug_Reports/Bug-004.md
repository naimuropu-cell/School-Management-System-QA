# BUG-004 - System Allows Duplicate Leave Requests for the Same Leave Type and Date Range

## Bug ID
BUG-004

---

## Module
Leave Management

---

## Feature
Apply Leave / Leave Approval

---

## Bug Title
System allows duplicate leave requests for the same leave type and identical date range.

---

## Environment

| Parameter | Value |
|-----------|-------|
| Application | School Management System |
| Module | Leave Management |
| Browser | Google Chrome |
| Operating System | Windows 11 |
| User Role | Student / Admin |
| Build | Current Testing Build |

---

## Preconditions

- Student account is active.
- Student can access the Leave module.
- Admin has permission to approve leave requests.
- Student has not exceeded the allowable leave limit.

---

## Steps to Reproduce

1. Login as **Student**.
2. Navigate to **Leave → Apply Leave**.
3. Submit a leave request using:
   - Leave Type: **Sickness**
   - From Date: **23-Jul-2026**
   - To Date: **27-Jul-2026**
4. Login as **Admin**.
5. Navigate to **Leave Approval**.
6. Approve the submitted leave request.
7. Login again as **Student**.
8. Submit another leave request using the **same Leave Type** and the **same From and To dates**.
9. Login as **Admin**.
10. Approve the second leave request.
11. Open the leave request list.

---

## Test Data

| Field | Value |
|--------|-------|
| Leave Type | Sickness |
| From Date | 23-Jul-2026 |
| To Date | 27-Jul-2026 |

---

## Expected Result

The system should prevent duplicate leave requests for the same student with the same Leave Type and overlapping or identical date range.

The system should display a validation message such as:

> **"A leave request already exists for the selected leave period."**

or

> **"Duplicate leave request is not allowed."**

---

## Actual Result

The system accepts the duplicate leave request without any validation.

Both leave requests can be approved successfully by the Admin, resulting in multiple approved leave records for the same student, leave type, and leave period.

---

## Impact

- Duplicate leave records are created.
- Leave history becomes inconsistent.
- Leave statistics and attendance reports may become inaccurate.
- Business rules for leave management are violated.
- Users can misuse the leave system by submitting identical requests multiple times.

## Root Cause (Possible)

- Duplicate leave validation is missing before saving a leave request.
- Date overlap validation is not implemented.
- Leave approval process does not verify existing approved leave records.
- Business rules for duplicate leave prevention are not enforced.

---

## QA Comments

The application should not allow multiple approved leave requests for the same student covering the same leave period. Proper validation should be implemented during leave submission and approval to prevent duplicate records.

---

## Suggested Fix

- Check for existing leave requests before saving a new request.
- Validate overlapping leave periods.
- Prevent duplicate approval of identical leave requests.
- Display a meaningful validation message when a duplicate request is detected.
