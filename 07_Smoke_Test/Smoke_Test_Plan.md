# Smoke Test Plan

## Project

School Management System

---

# Objective

The objective of Smoke Testing is to verify that the core functionalities of the School Management System are working correctly after a new build or deployment.

Smoke Testing ensures that the application is stable enough for further Functional and Regression Testing.

---

# Smoke Test Scope

The following critical modules are included:

- Authentication
- Dashboard
- User Management
- Student Management
- Admission
- Teacher Management
- Academics
- Attendance
- Homework
- Examination
- Finance
- Reports

---

# Entry Criteria

- New Build Deployed
- Database Available
- QA Environment Ready
- Smoke Test Data Available

---

# Exit Criteria

- Critical Smoke Test Cases Passed
- No Blocker Issue Found
- Build Stable For Functional Testing
