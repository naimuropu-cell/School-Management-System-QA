# 🎓 School Management System - QA Portfolio

A comprehensive **Software Quality Assurance (SQA)** repository for a School Management System.

This repository contains real-world QA documentation, test artifacts, bug reports, API testing, automation framework, SQL validation, and user documentation created while testing a complete School ERP application.

---

# 📌 Project Overview

This project demonstrates end-to-end QA activities performed on a School Management System including:

- Functional Testing
- UI Testing
- Validation Testing
- Regression Testing
- Smoke Testing
- Sanity Testing
- API Testing
- Database Validation
- Selenium Automation
- Postman Automation
- Business Rule Documentation
- User Guide Preparation
