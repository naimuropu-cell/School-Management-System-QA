# API Testing

## Project

School Management System

---

## Overview

This folder contains all API testing artifacts created during the testing of the School Management System.

The APIs were validated to ensure that the backend services function correctly, securely, and consistently across different modules.

---

# Objectives

- Verify API functionality
- Validate request and response data
- Verify status codes
- Test authentication & authorization
- Validate CRUD operations
- Verify business rules
- Perform negative testing
- Validate API performance
